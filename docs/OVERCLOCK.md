# Настройка охлаждения и OVERCLOCK

Открой OVERCLOCK и поставь галочку о риске. Она только открывает вкладку. Отметь конкретную настройку, введи значение и нажми «Применить». Сброс возвращает настройки, которые действовали до первого изменения через Burmalk. Если драйвер отклоняет запись, приложение сообщает ошибку и пытается отменить частичные изменения. Эти действия не заменяют резервное копирование и диагностику стабильности.

## Видеокарта

NVIDIA NVML загружается из системного каталога драйвера. На совместимых картах доступны ядро и память в режиме P0, лимит мощности и ручные вентиляторы. Новые драйверы используют `nvmlDeviceGetClockOffsets` / `nvmlDeviceSetClockOffsets`; старые проверяются через доступные legacy-функции. Пределы читаются из драйвера и дополнительно ограничиваются интерфейсом: ядро до ±250 MHz, память до ±1000 MHz. Это не обещание стабильности этих значений. Напряжение GPU не меняется. AMD / Intel без соответствующего поддерживаемого backend не получают фиктивных регуляторов.

## Процессор

BOOST CPU управляет активным планом питания Windows для сети: PERFBOOSTMODE, максимальное состояние процессора и предел частоты. Настройка Windows не гарантирует точную частоту; её соблюдение зависит от CPU/прошивки. Ручной множитель, напряжение и PPT требуют BIOS / утилиты производителя. При смене активного плана настройка блокируется до перезапуска Burmalk. Восстановление изменяет исходный план, но не переключает обратно план, который пользователь выбрал отдельно.

## Вентиляторы

В CPU показан один регулятор «Скорость кулера CPU» с кнопками «Применить скорость» и «Авто». Если плата не подписала CPU_FAN и назначения ещё нет, нажми «Настроить кулер CPU»: в отдельном окне один раз выбери предоставленный платой PWM-контроллер (%) и датчик оборотов (RPM), сверь с CPU_FAN в BIOS, отметь подтверждение и сохрани назначение. Общие каналы Nuvoton не показываются на основном экране CPU. Это сохраняет только идентификаторы каналов и платы, не меняет скорость. При последующем запуске назначение восстановится только для той же платы и существующих каналов. Без явного, уникального названия CPU_FAN автоматического назначения нет: номер Fan # и совпадение индексов PWM/RPM не доказывают, что это вентилятор CPU. Неизвестное назначение блокирует ручное управление. Для доступа к плате нужны права администратора и поддерживаемый драйвер; иначе показана причина недоступности. GPU предлагает обнаруженные контроллеры NVIDIA. Ручная скорость 40–100% дополнительно ограничивается диапазоном драйвера. «Авто» передаёт управление прошивке. Предыдущая ручная политика GPU сохраняется для возврата.

## Восстановление и проверки

Значения не применяются при запуске. Обычный выход возвращает только изменения текущей сессии Burmalk. При CPU ≥90°C / GPU ≥85°C либо недоступной соответствующей температуре проверка раз в три секунды пытается восстановить изменённую группу. Это не защита от всех аппаратных повреждений. Аварийное завершение, зависший драйвер или питание могут прервать восстановление. Не используй параллельную утилиту, которая постоянно перезаписывает те же настройки.

Автоматические тесты TuningTests проверяют диапазоны, частичные ошибки, повторное применение, восстановление исходных значений и политику вентиляторов на имитируемом драйвере. `--probe` только читает реальные возможности GPU и настройки Windows. UI-проверка открывает вкладку по галочке, но не применяет разгон. Фактическая запись аппаратных параметров на пользовательском ПК автоматическими тестами не проверяется.
