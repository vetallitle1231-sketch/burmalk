# Сайт Burmalk — обновлённая версия

Сайт находится в `website/index.html`. Открывается без сервера через ярлык «Сайт Burmalk» на рабочем столе. HTML, CSS, JavaScript и изображения локальные; сторонние библиотеки и шрифты не загружаются.

Включены шесть настоящих скриншотов экспериментальной 1.1.8, галерея с увеличением и переключением стрелками, интерактивная CSS 3D-модель компьютера, описание возможностей и ограничений, блок версий и вопросы по установке. Модель — иллюстрация, не чтение оборудования посетителя. Вращение вентиляторов приостанавливается вне видимой области; режим уменьшения анимации учитывается.

На сайте доступны две отдельные кнопки скачивания: стабильная 1.1.7 и экспериментальная 1.1.8. Оба установщика находятся в GitHub Releases; ссылки используют явные теги и точные имена файлов. Релиз 1.1.8 опубликован как prerelease и не заменяет основную 1.1.7. Он связан с исходниками в ветке experimental/1.1.8. Публичный SHA256 установщика совпал с локальным файлом.

- 1.1.7: https://github.com/vetallitle1231-sketch/burmalk/releases/download/v1.1.7/Burmalk-Setup-1.1.7.exe
- 1.1.8: https://github.com/vetallitle1231-sketch/burmalk/releases/download/v1.1.8/Burmalk-Setup-1.1.8.exe

Установщики не нужно помещать в ZIP сайта: один файл Cloudflare Pages ограничен 25 МиБ, а каждый установщик занимает больше 60 МиБ. Кнопка передаёт скачивание GitHub; ПК владельца для этого не требуется. После загрузки нового ZIP в Production обе версии можно скачать с работающего сайта.

## Обновить существующий Cloudflare Pages

1. В аккаунте Cloudflare открой Workers & Pages → существующий проект **burmalk**.
2. Выбери **Create deployment** и окружение **Production**.
3. Загрузи `dist/Burmalk-Website-2.0.zip`: в корне архива находятся index.html, styles.css, app.js и assets.
4. Нажми **Save and deploy** и дождись успешного результата. Открой URL проекта и проверь галерею и скачивание.

ZIP не содержит исходников программы, персональных настроек или установщика. Менять DNS и домен для обновления файлов сайта не нужно. Предыдущие файлы сайта сохранены в `.build/website-before-redesign-20261011`.

## Проверки

Проверены галерея всех шести экранов, увеличение и закрытие Escape, выбор компонентов 3D, поворот с клавиатуры и сброс, загрузка изображений, локальные ссылки и отсутствие горизонтальной прокрутки. Мобильная и планшетная компоновка проверены во фреймах 390/768 px; основной браузер — 1101 px. Скриншоты проверки находятся в `.build/website-preview`.

Публикация в текущем запуске не выполнена: доступная панель Cloudflare показывает “The Cloudflare Dashboard is temporarily unavailable”. Публичный URL burmalk.pages.dev вернул HTTP 404, домен burmalk.online не разрешился через текущий системный DNS. Это результаты отдельных проверок, не вывод о состоянии всего сервиса Cloudflare.
