# Сайт Burmalk 1.1.11

Основная версия на сайте — 1.1.11. Другие версии не предлагаются. Код находится в `website`, готовый архив для Cloudflare — `dist/Burmalk-Website-1.1.11.zip`.

Тёмный минималистичный дизайн с бирюзовым акцентом: краткое введение, галерея, мониторинг/состояние, PC RANK, прозрачный FPS-оверлей, все остальные функции, скачивание, FAQ и связь по **Burmalk3@gmail.com**. Почтовая ссылка подставляет тему ошибки и не отправляет письмо автоматически. Установщик скачивается из GitHub Releases.

## Настоящая модель из приложения

`scripts/WebsiteModelExporter` ссылается на `PcModelScene.cs`, `PcModelRotor.cs`, `PcModelOptions.cs` приложения. Экспорт `CompleteTower` даёт 73 286 вершин, 59 080 треугольников, 57 групп рисования и 10 роторов. Статическая геометрия объединена по материалу и компоненту. Преобразования вертикальной GPU и оси/центры вентиляторов сохранены. Геометрия и манифест находятся в `assets/model/pc.bin` / `pc.json`.

Веб-визуализация использует локально включённый Three.js 0.186.1 с MIT-лицензией. Модель вращается перетаскиванием или стрелками; компоненты выбираются кнопками и прямым нажатием. Есть сброс ракурса. Это иллюстрация, сайт не читает оборудование посетителя.

Постоянного вращения камеры нет. В обычном состоянии кадр рисуется по событию, а не в цикле. Вентиляторы выключены по умолчанию; их можно включить вручную. Движение ограничено 20 FPS и останавливается вне видимой области, при скрытии/потере фокуса и при `prefers-reduced-motion`. При недоступном WebGL остаётся постер. Если открыть HTML напрямую как файл, галерея и текст работают, интерактивное 3D заменяется постером; для 3D нужен HTTP.

## Размещение

Используется прежний Cloudflare Pages-проект **burmalk** и существующий домен **burmalk.online**. Архив содержит файлы сайта в корне; установщик в него не включён. Для обновления проекта применяется Production deployment. DNS и аккаунт менять не нужно.

Перед изменениями сайт сохранён в `.build/website-before-main-1.1.11-20261014`. Источник модели и папки пользователя в ZIP не попадают.
