Burmalk 1.1.2 — исправление замены фона из фото.

Каждое выбранное изображение сохраняется отдельно и загружается без устаревшего кэша. В Settings появился предпросмотр, сохраняется исходное имя фото, можно убрать фон. Если импорт не удался, программа показывает ошибку и сохраняет предыдущий фон.

Выбор изображения также показывает WebP/GIF. Для открытия таких файлов используется установленный в Windows кодек; сохранённый фон — PNG.

Надписи и графики остаются непрозрачными. Шапка и боковое меню не просвечивают сквозь выбранную картинку.

Установите Burmalk-Setup-1.1.2.exe поверх предыдущей версии, затем выберите фото через Settings → Choose photo from PC. Изображение применяется сразу.
