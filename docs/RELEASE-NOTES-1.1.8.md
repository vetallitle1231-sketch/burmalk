# Burmalk 1.1.8 экспериментальная версия

- На главной вкладке можно скрывать и возвращать карточки, свободно размещать их мышью за заголовок. Координаты сохраняются между запусками. Большое рабочее поле прокручивается; есть кнопка сброса расположения.
- Во вкладке Network — ручная проверка загрузки, отдачи и задержки HTTP. При отказе Cloudflare автоматический режим переключается на LibreSpeed CESNET; сервер можно выбрать вручную. Измеренные показатели сохраняются при частичном результате. Используются только сгенерированные тестовые данные; расход до 128 МиБ на сервер, до 256 МиБ с резервной попыткой, есть остановка. Это оценка скорости до выбранного сервиса, не гарантированная скорость тарифа.
- Во вкладке Disk Activity можно выбрать каждый доступный локальный том и проверить последовательное чтение и запись 128 МиБ. Тест использует отдельный временный файл, обход файлового кэша Windows и удаление файла после завершения/остановки. При необходимости можно выбрать доступную папку на том же диске. Это тест скорости, не проверка здоровья накопителя.
- Музыкальная карточка показывает обложку, если Spotify или SoundCloud передаёт её через системные медиаданные Windows.
- Во вкладке Gaming есть библиотека установленных Steam-игр и игровых ярлыков из меню «Пуск». Игру также можно добавить по `.exe`, запускать и удалять из пользовательского списка.
- Библиотека Gaming занимает верхнюю часть страницы: крупные карточки, поиск, иконки из локального Steam-кэша или исполняемого файла. При отсутствии картинки используется значок геймпада. Текущая игровая сессия раскрывается отдельно.
- В шапке GPU показана частота ядра. Частота видеопамяти по шкале NVIDIA SMI показывается отдельно с указанием источника. Неподтверждённые коэффициенты пересчёта не используются.
- CPU_FAN назначается по отдельным PWM и RPM каналам. Если плата не подписывает CPU_FAN однозначно, управление заблокировано до подтверждения и сохранения назначения пользователем; оно сохраняется для конкретной платы. Fan #1 не считается CPU_FAN автоматически.
- В CPU / GPU добавлены ручная скорость вентиляторов, автоматическое управление прошивкой и возврат предыдущих настроек. GPU использует NVIDIA NVML. CPU_FAN доступен только при поддержке контроллера материнской платы через LibreHardwareMonitor и правах администратора; назначение разъёма нужно проверить по BIOS, а не угадывать по номеру Fan #.
- OVERCLOCK выделен красной рамкой. Перед входом нужна галочка о риске. GPU: смещения ядра/памяти P0 и лимит мощности по возможностям драйвера; CPU: буст и ограничения активного плана Windows при питании от сети. Множитель, напряжение и PPT CPU не поддерживаются. Неотмеченные настройки не меняются; автоматического применения при старте нет.
- Проверка CPU и RAM длится около минуты: измеряет производительность одного ядра CPU и проверяет запись/чтение 128 МиБ RAM. Это не замена диагностике всех планок памяти.
- Отдельный двухминутный 3D-тест измеряет средний FPS сцены Direct3D. Баллы Burmalk равны среднему FPS × 100; это внутренняя оценка, сравнимая только при одинаковом компьютере и версии. Тест остановится при 90 °C GPU или 95 °C CPU, если датчики доступны, и может быть остановлен вручную.
- Значок внизу навигации включает запуск Burmalk вместе с Windows. Положение карточек, видимые карточки, внешний вид, игровые пути и другие настройки сохраняются в папке пользователя.

CPU показывает один ползунок скорости кулера; выбор каналов платы вынесен в отдельную однократную настройку CPU_FAN. Неопределённый разъём не выбирается автоматически.

В «Состояние ПК» добавлены четыре цветные оценки текущих показателей и пояснения. Неполные данные обозначены отдельно; SMART не проверяется. Подробности: [SYSTEM-HEALTH.md](SYSTEM-HEALTH.md).

## Примечания

Фирменная тема **Burmalk** объединяет тёмно-синий, фиолетовый, чёрный и бирюзовый с мягким градиентом. На главной есть «Пульс ПК» с живыми графиками CPU/GPU/RAM, быстрые переходы к играм и бенчмарку; кнопка «Виджеты» открывает настройку карточек. Другие темы и собственный фон по-прежнему доступны в настройках.

Разгон — экспериментальная функция. Поддержка отдельных регулировок зависит от оборудования и драйвера. Перед применением требуется доступная температура. Ручная скорость вентиляторов ограничена минимумом 40% и диапазоном драйвера. При CPU ≥90°C / GPU ≥85°C или потере соответствующего датчика Burmalk пытается вернуть изменённые им настройки. Кнопка возврата и обычное закрытие возвращают значения, действовавшие до первой настройки в Burmalk, включая прежний ручной режим вентилятора; они не устанавливают заводские значения. При аварийном завершении программы восстановление не гарантировано. Не применяй настройки одновременно с другой утилитой разгона.

Экспериментальная 1.1.8 устанавливается рядом со стабильной 1.1.7, имеет отдельный ярлык и отдельную папку настроек `%LocalAppData%\Burmalk-Experimental`. Публичная стабильная 1.1.7 и её установщик не меняются. У некоторых игр Steam путь запуска может отличаться; такие игры можно добавить вручную. Каталог Windows Media не гарантирует обложку, если музыкальное приложение её не передаёт.
