Датчики CPU в Burmalk

Температуру и среднюю частоту ядер читает LibreHardwareMonitor 0.9.6.
Для температуры требуется подписанный драйвер PawnIO и права администратора.
1. Запустите Support/PawnIO_setup.exe вручную и установите обычную подписанную версию.
2. Закройте Burmalk и откройте ярлык через «Запуск от имени администратора».
Если датчик не поддерживается или доступ запрещён, приложение сообщает об этом.
Защиту Windows, Secure Boot и изоляцию ядра отключать не нужно.
Без доступа к аппаратным датчикам частота читается из Windows power API; это сообщённая Windows частота, которая может не учитывать boost.
Для захвата FPS через ETW также нужны права администратора.

Официальный сайт драйвера: https://pawnio.eu/
Исходный код: https://github.com/namazso/PawnIO
Источник установщика: https://github.com/namazso/PawnIO.Setup/releases
Подписант установщика: namazso.eu.
