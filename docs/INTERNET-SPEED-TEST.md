# Burmalk: исправление отказов сервера проверки скорости

При ответе Cloudflare 403/429 или ошибке соединения режим «Автоматически» переходит на публичный сервер LibreSpeed CESNET в Праге. Можно явно выбрать сервер в Network. Никакие браузерные cookies, обход проверки или пользовательские файлы не используются.

Если оба сервиса недоступны, отображается понятное сообщение. Если измерена только загрузка, результат сохраняется, а отдача помечается «недоступно»; нулевые или выдуманные показатели не подставляются. При смене сервера замеры начинаются заново, чтобы не смешивать скорости разных серверов; общий расход тестовых данных учитывает и неудачную попытку.

Ограничение: до 128 МиБ на сервер, до 256 МиБ при резервной попытке. Отмена пользователя останавливает все попытки. Внешние сервисы могут быть недоступны независимо от приложения.

Проверки: `dotnet run --project tests/SpeedTests/SpeedTests.csproj -c Release`. Флаг `--live` проверяет реальные endpoints малыми запросами; `--full` выполняет полный тест Cloudflare/автоматического режима, `--fallback-full` — полный тест LibreSpeed. Полные тесты запускаются только явно.

Протоколы и сервер:
- https://github.com/cloudflare/speedtest
- https://github.com/librespeed/speedtest/blob/master/backend/garbage.php
- https://librespeed.org/backend-servers/servers.php
