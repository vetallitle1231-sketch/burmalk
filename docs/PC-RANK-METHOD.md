# PC RANK: burmalk-relative-v1

Это версия методики тестов Burmalk, а не промышленный рейтинг комплектующих, результат FurMark или обещание FPS в играх. Используются измерения, а не название/цена оборудования. Универсальные пороги для всего рынка без набора измерений разных ПК обосновать нельзя; поэтому первая методика имеет открытый измеренный эталон и геометрические диапазоны относительной производительности.

## Измерения

- GPU: существующая двухминутная сцена WPF/Direct3D с 120 сферами, общим замороженным mesh, двумя направленными источниками света. Камера 52°, виртуальный viewport 960 × 540, окно 1180 × 760. Результат = число уникальных событий кадра / фактическое время. Старая шкала GPU = FPS × 100.
- CPU: существующая целочисленная зависимая цепочка multiply/add, один worker, 60 секунд. Результат = миллионы итераций в секунду; число ядер не добавляет баллы.
- RAM: 128 МиБ UInt64, четыре прохода записи/чтения каждого элемента с проверкой детерминированного шаблона. Результат = 8 × размер буфера / время / 1 000 000, MB/s. Это ограниченная проверка и скорость данного алгоритма, не MemTest и не скорость всей установленной памяти.

Полный подтверждённый ранг выдаётся только после одного полного прохода PC RANK. Два отдельных теста в Benchmark не складываются в подтверждённый ранг. Отмена, закрытие GPU-окна, программный рендеринг без аппаратного tier, перегрев по доступным датчикам, остановившийся мониторинг, недостающие/NaN/Infinity результаты не подтверждают ранг. Новая неудачная попытка не стирает старый успешный результат.

## Нормализация

Для каждого компонента: `normalized = raw / reference × 1000`.

`total = GPU × 0.50 + CPU × 0.35 + RAM × 0.15`.

|---|---|---:|---|
| BRONZE | D | 250 | четверть |
| SILVER | C | 500 | половина |
| GOLD | B | 1000 | один |
| DIAMOND | A | 2000 | два |
| LEGENDARY | S | 4000 | четыре |

Границы — геометрические середины соседних уровней: `250 × √2`, `500 × √2`, `1000 × √2`, `2000 × √2` (около 353.55, 707.11, 1414.21, 2828.43). Самый низкий/высокий диапазон открыт с края. Это уровни удвоения измеренной пропускной способности, а не выдуманные процентили. Эталон находится в середине GOLD; небольшой естественный разброс не перекидывает его между рангами. Точный ранг считается до форматирования. Выводимый целый балл округляется вниз.

Повторный полный проход дал CPU 1116.3352756560107 млн итераций/с, RAM 9251.251019907035 MB/s, GPU 129.8907085757586 FPS. Разброс относительно эталона: GPU −1.04%, CPU −2.43%, RAM −5.59%; общий индекс около 978. Сырая запись и реальный полный проход проверены; распределение результатов разных моделей ПК ещё не исследовано. Файлы проверки остаются локально.

После изменения алгоритма/сцены/эталона нужна новая версия методики. Смена CPU, выбранной GPU или объёма RAM помечает сохранённый ранг как требующий повторного тестирования.

## Ограничения

WPF FPS зависит также от CPU, композитора Windows, драйвера, масштаба/DPI, частоты экрана, фона и видимости окна. Ранги следует сравнивать в одинаковых условиях и одной методике. Эталон одного ПК не подтверждает объективную сравнительную мощность всех GPU. CPU-тест измеряет один поток. RAM-тест затрагивает только выделенный буфер. Отсутствие датчика температуры показывается честно; защита работает только по доступным актуальным датчикам. Автоматический разгон не запускается.

WPF реализован на текущих технологиях проекта. Основание для выбора камеры, geometry и замораживания статических ресурсов: [Microsoft: 3D Graphics Overview](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/graphics-multimedia/3-d-graphics-overview), [Maximize WPF 3D Performance](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/graphics-multimedia/maximize-wpf-3d-performance).

## Сохранение и приватность

`performance.json` содержит только полный последний результат PC RANK; `benchmarks.json` — результаты отдельных тестов для паспорта. Оба файла локальные, атомарно заменяются через временный файл, исключены из Git. Настройки паспорта и эффектов остаются в settings.json. PDF экспортирует растровые страницы высокого разрешения; текст можно прочитать, но он не выделяется как PDF-текст. Сохранение через стандартный выбор файла, без облачных запросов.
