Burmalk 1.1.0 — мониторинг компьютера для Windows 10/11 x64.

Скачайте Burmalk-Setup-1.1.0.exe, пройдите установку и откройте Burmalk через ярлык. .NET включён; интернет для установки не требуется.

В этом выпуске: цветовые темы, светлая тема, аниме-фон и своё фото, компактный вид, прозрачный оверлей BURMALK, новые измерения бенчмарка и источник датчиков CPU.

Температура CPU требует подписанного PawnIO и запуска от администратора. Его установщик и инструкция находятся в Support рядом с Burmalk.exe. Для FPS через ETW также нужны права администратора. Обычный мониторинг запускается без повышения прав.

Доступность датчиков зависит от оборудования. GPU benchmark не реализован; раздел показывает реальные показания GPU. Чтение диска в бенчмарке может включать кэш Windows. Frame-time lows 1%/0.1% пока не вычисляются. Установщик Burmalk не подписан цифровой подписью издателя.

Иконка и аниме-фон сгенерированы с помощью imagegen; свои фотографии остаются локально на компьютере пользователя.
