# Проверка Burmalk 1.1.9

Дата: 13.10.2026. Все служебные запуски имеют отдельную папку данных и не меняют настройки/историю пользователя. Результаты и снимки находятся в `.build`, не публикуются как диагностические данные пользователя.

- Сборка Release и self-contained win-x64 проходят без ошибок и предупреждений компилятора.
- UI-проход открывает все 19 вкладок, прежние темы, фон, OVERCLOCK за воротами согласия; аппаратные параметры разгона и ручные PWM во время проверки не применяются.
- В полном проходе GPU-сцена работает 120.4012217 с, CPU — 60.0000033 с; четыре прохода записи и чтения 134217728 байт RAM проходят успешно.
- Сырые результаты: GPU 129.8907085757586 FPS; CPU 1116.3352756560107 млн итераций/с; RAM 9251.251019907035 MB/s. Итог burmalk-relative-v1: GOLD / B, 977 целых баллов.
- Пиковые доступные показания GPU: 32 °C, 3202 MHz. Датчик температуры CPU в неадминистративном проверочном процессе недоступен: значение не выдумывается. Здесь не подтверждён датчик CPU с повышенными правами, управление вентиляторами на разных платах или разгон других моделей.
- После перезапуска готовой self-contained сборки реальный сохранённый результат снова показан в PC RANK и PC PASSPORT. Проверяется отдельное чтение DataStore и сохранение настроек оформления/приватности/эффектов.
- PNG создаётся в трёх оформлениях 1600 × 1120 и вертикальном формате 1080 × 1920. PDF проверен как файл с корректной структурой и отрисован через PDFium; две страницы имеют читаемые характеристики, без обрезанных блоков. PDF содержит растровые страницы, без выделяемого текста.
- 3D: все шесть групп выбираются, камера приближает/отдаляет в ограниченном диапазоне, ресурсные mesh заморожены; таймер останавливается при скрытии/выгрузке вкладки. Поддерживается hit testing мышью, вращение/масштаб и клавиатура. Точное соответствие внешнему виду реальных компонентов не заявляется.
- Математические проверки охватывают центры пяти рангов, обе стороны всех границ, вес каждого компонента, отсутствие/NaN/Infinity/неполные результаты, неподдерживаемый render tier, старую методику, смену оборудования и отмену до старта нагрузки. Имена комплектующих не повышают балл.
- Существующие проверки HealthTests, TuningTests и SpeedTests проходят; ручной разгон и вентиляторы проверяются на изолированных имитациях аппаратных контрактов, не изменением оборудования пользователя. SpeedTests используют свой временный дисковый файл и удаляют только его.

Ограничение ранга: измерены условия одной реальной сборки, не парк разных ПК. WPF FPS зависит также от CPU, Windows, драйвера, DPI и экрана. Методика подробно объяснена в PC-RANK-METHOD.md; ранг — относительный индекс Burmalk, не универсальная оценка игровой мощности.
