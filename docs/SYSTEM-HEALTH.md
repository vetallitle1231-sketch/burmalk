# Состояние ПК

Вкладка показывает текущую оценку по доступным данным: **Отлично** (зелёный), **Хорошо** (жёлтый), **Неплохо** (оранжевый), **Плохо** (красный).

Итог — худшая оценка из температуры CPU/GPU, заполнения RAM/VRAM и каждого доступного локального или съёмного тома. Это пороги интерфейса Burmalk для текущих условий, а не диагноз исправности оборудования и не спецификация производителя.

| Показатель | Хорошо от | Неплохо от | Плохо от |
|---|---:|---:|---:|
| Температура CPU | 70 °C | 80 °C | 90 °C |
| Температура GPU | 65 °C | 75 °C | 85 °C |
| Использование RAM | 75% | 90% | 97% |
| Использование VRAM | 80% | 92% | 98% |
| Заполнение тома | 85% | 93% | 98% |

Значения ниже первого порога относятся к зелёной зоне. Неизвестные, некорректные и устаревшие (старше 30 секунд) показания не оцениваются. При отсутствии важного показателя зелёный итог ограничивается жёлтым «Хорошо», с заметной пометкой «Неполная оценка» и списком недоступных данных. При полном отсутствии оценённых показателей выводится «Нет данных». Доступное критическое значение всегда сохраняет красный итог, даже если другие датчики недоступны.

Загрузка CPU/GPU, частоты, мощность, активность дисков, сетевой трафик и доступные обороты представлены для контекста. Высокая загрузка в игре, отключённая сеть или остановка вентилятора GPU в простое сами по себе не ухудшают оценку. CPU_FAN читается только по назначенному разъёму. SMART сейчас не получен; проверка исправности накопителей по SMART не выполняется.

Алгоритм только читает данные и не изменяет частоты, мощность или охлаждение.
