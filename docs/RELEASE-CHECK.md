# Проверка Burmalk 1.1.6 — 10.10.2026

Burmalk 1.1.6 использует только игровой оверлей RTSS. Отдельное окно оверлея и его настройки расположения удалены. Показываются FPS, средний FPS по измерениям текущего процесса, время кадра, доступные датчики CPU/GPU, VRAM, RAM и сеть. Недоступные значения не подменяются выдуманными. Логика усреднения сбрасывается при смене процесса игры.

RTSS 7.3.7 установлен на этом ПК. Проверка доступа без изменения данных подтвердила область RTSSSharedMemoryV2 с правом чтения и записи (signature 0x52545353, protocol 0x00020015, 256 игровых записей, 8 слотов OSD). 18 изолированных проверок протокола подтвердили чтение FPS/времени кадра, запись и очистку собственного вторичного слота, сохранение чужого слота, обработку занятой области и ошибочных размеров. Ещё 18 проверок логики включения, скрытия и возврата оверлея прошли.

Самопроверка опубликованной сборки: 24 страницы и состояния, 0 ошибок. Установщик 1.1.6 завершился с кодом 0; SHA256 установленной Burmalk.dll совпадает с опубликованной сборкой: F73A725473AB34FA59B88A96749CAE8C35BBE87C6C97F399E17BEFCE54B19EC6. Настройка OverlayEnabled включена, горячая клавиша F8 сохранена. Ярлык рабочего стола указывает на установленный Burmalk.exe. В dist оставлен только актуальный установщик и инструкция.

SHA256 Burmalk-Setup-1.1.6.exe: 0835DD31DEC9D726D44DE9FFEAEA2A52F8B19C57481CC6976E14F009C6FB54F6.

Пользователь просил не мешать игре. Dota 2 не запускалась и её режим отображения не менялся. Пока пользователь играл в How to Fish, проверка только на чтение подтвердила подключение игрового PID 7656 к RTSS (344,5 FPS, 2,28 мс в момент чтения) и присутствие собственного слота Burmalk. В нём находились реальные показатели: FPS, AVG FPS, FRAME, CPU с температурой и MHz, GPU с температурой и частотой, VRAM, RAM и сеть. Проверка не нажимала клавиши, не меняла настройки и не переключала окна. Видимость нового RTSS OSD в настоящем fullscreen Dota 2 не подтверждена визуально; если игра запущена до RTSS, она может потребовать перезапуск. Совместимость ограничена поддержкой RTSS со стороны игры и античита.

## Предыдущая проверка 1.1.4 — 10.10.2026

## Предыдущая проверка 1.1.3 — 09.10.2026

Причина отсутствия оверлея в How to Fish подтверждена кодом: процесс не входил в список игр, а показ был ограничен обнаруженной игровой сессией. F8 менял только общую настройку и не обходил это ограничение.

13 автоматических проверок исправленной логики показа прошли: неизвестная игра, повторное нажатие, распознанная игра, отключённый профиль, ручное включение, предварительный просмотр и возврат к автоматическому режиму. Проверки запускаются без окон, регистрации горячих клавиш и доступа к игре: `dotnet run --project tests/OverlayVisibility/OverlayVisibility.csproj -c Release`.

Сборка 1.1.3 включает исправления фона из 1.1.2. В 1.1.2 проверены 25 состояний интерфейса, последовательная замена двух фото с одинаковым именем, сохранение прежнего фона при ошибке и импорт выбранного WebP; ошибок нет (`.build/verification-photo-final-1.1.2`).

Из уважения к текущей игровой сессии 1.1.3 не установлена поверх работающей программы. Нажатие F8 в реальной игре и поведение в её полноэкранном режиме пока не проверялись. Новую версию нужно установить после завершения игры.
