# Проверка Burmalk 1.1.3 — 09.10.2026

Причина отсутствия оверлея в How to Fish подтверждена кодом: процесс не входил в список игр, а показ был ограничен обнаруженной игровой сессией. F8 менял только общую настройку и не обходил это ограничение.

13 автоматических проверок исправленной логики показа прошли: неизвестная игра, повторное нажатие, распознанная игра, отключённый профиль, ручное включение, предварительный просмотр и возврат к автоматическому режиму. Проверки запускаются без окон, регистрации горячих клавиш и доступа к игре: `dotnet run --project tests/OverlayVisibility/OverlayVisibility.csproj -c Release`.

Сборка 1.1.3 включает исправления фона из 1.1.2. В 1.1.2 проверены 25 состояний интерфейса, последовательная замена двух фото с одинаковым именем, сохранение прежнего фона при ошибке и импорт выбранного WebP; ошибок нет (`.build/verification-photo-final-1.1.2`).

Из уважения к текущей игровой сессии 1.1.3 не установлена поверх работающей программы. Нажатие F8 в реальной игре и поведение в её полноэкранном режиме пока не проверялись. Новую версию нужно установить после завершения игры.

## Предыдущая проверка CPU — 1.1.1

На ПК с AMD Ryzen 7 5700X обнаружена неполная установка PawnIO: служба была зарегистрирована, но устройство отсутствовало (Win32 error 2). Запуск службы сам по себе не создавал устройство. Официальный подписанный установщик 2.2.0 завершил восстановление с кодом 0; устройство ROOT\PAWNIO\0000 получило статус OK.

Установленная копия Burmalk 1.1.1 проверена с обязательным наличием реальной температуры (`--require-cpu-temperature`): 25 состояний страниц, тем и оверлея, Failures: 0. Последний замер CPU: 57,375 °C и 4486 MHz; источник LibreHardwareMonitor, аппаратный датчик Core (Tctl/Tdie). На снимках CPU, Gaming и Overlay также присутствуют реальные изменяющиеся значения температуры и частоты.

Проверены сохранение/чтение температуры игровых сессий, настройки, профили, отсутствие подмены недоступных значений, работа бенчмарка и прозрачность оверлея. Полная игровая сессия и другой физический ПК после этих изменений не проверялись.

Установщик и установленная программа обновлены до 1.1.1. SHA256 установленной Burmalk.dll совпадает со сборкой. Ярлык на рабочем столе ведёт на установленный Burmalk.exe. Для этого пользователя включено сохранение запроса прав для датчиков при запуске; в Settings его можно отключить.
